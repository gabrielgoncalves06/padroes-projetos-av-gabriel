# padroes-projetos-av-gabriel

Compilar e executar (a partir da pasta de cada questão):

    cd questao1 && mkdir out && javac -d out src/*.java && java -cp out Main
    cd questao2 && mkdir out && javac -d out src/*.java && java -cp out Main

A questão 1 lê `config.properties` do diretório de execução (`questao1/`).
